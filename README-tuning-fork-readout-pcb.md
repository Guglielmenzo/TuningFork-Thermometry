# Tuning Fork Readout PCB

Senior design project: readout PCB and interface electronics for Maybell Quantum's
tuning fork thermometer.

## Status

Just getting started — no schematic, requirements doc, or firmware yet. Fill in
design requirements and meeting notes from Maybell Quantum in `docs/` as they come in.

## Tools

- Schematic/layout: KiCad (assumed default — update this if a different tool is used)

## Structure

- `hardware/pcb/` — schematic and layout files (KiCad)
- `hardware/datasheets/` — component datasheets
- `firmware/` — microcontroller / readout interface code, if applicable
- `docs/` — requirements, design decisions, meeting notes with Maybell Quantum
- `test/` — validation and calibration data
